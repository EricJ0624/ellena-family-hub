범위: 기록만. 앱 코드, 위젯 크기, 배치, 기능, 인증, API, DB는 수정하지 않음.

## 역할과 칸 크기

위젯 칸 숫자는 역할이 아니라 그룹에 저장된다. 같은 그룹의 일반 사용자와 그룹 관리자는 같은 `widget_configs`를 쓴다.

역할에 따라 달라지는 것은 위젯 칸이 아니다.

- 그룹 관리자·그룹 소유자·시스템 관리자: 제목 옆에 관리 버튼 자리가 생기고, 제목 폭 계산이 관리자용이다. 하단 "관리자에게 문의"는 없다.
- 일반 사용자: 관리 버튼이 없고, 하단 "관리자에게 문의"가 있다.

그룹이 다르면 저장된 높이가 다르다. 역할마다 다른 그룹을 보고 있으면 대시보드 크기·정렬이 달라 보인다. 다른 그룹 행은 수정하지 않는다.

일반 사용자 기록은 헤더에 로그아웃만 있고 "관리자에게 문의"가 있는 화면이다. 그룹 관리자·시스템 관리자 기록은 아래 별도 절이다. 세 화면 모두 테마는 `kids_friendly`다.

알림 벨은 미확인 알림이 있을 때만 헤더에 붙는다 (`NotificationCenter`, 없으면 `null`). 버튼 칸은 36×36px이고, 숫자 배지는 칸 너비를 늘리지 않는다. 벨이 생기면 제목 간판만 좁아지고, 글자 크기는 간판 폭으로 다시 맞춘다. 위젯 칸 너비·높이·순서는 벨과 무관하다.

390px 키즈 테마 간판 너비. 줄 안쪽은 350px(본문 여백 32px, 줄 여백 8px). 간판과 오른쪽 묶음 사이는 12px. 관리 버튼은 그룹 관리자·시스템 관리자가 같은 "관리자" 라벨이라 76px로 같다. 색만 파랑/보라다. 벨과 관리 버튼이 같이 있으면 그 사이 8px가 더 빠진다. 시스템 관리자 벨 없음 262px는 화면에서 잰 값이고, 나머지는 같은 식이다.

| 역할 | 벨 없음 | 벨 있음 |
|---|---|---|
| 일반 사용자 | 338px | 302px |
| 그룹 관리자 | 262px | 218px |
| 시스템 관리자 | 262px | 218px |

화면의 `data-layout-h`는 DB 값을 그대로 쓰지 않는다. 불러올 때 예전 기본 높이를 코드 기본으로 바꾼다 (`lib/widgets/widget-configs.ts`).

- 여행 DB 6 → 화면 8
- 아기 성장 DB 9 → 화면 11
- 빠른 기록 5, 채팅 세로 8.5, 가족 로그 11, 위치 13은 그대로

이 화면 높이를 시드나 DB 숫자로 되돌리지 않는다.

## 화면 기록 (시스템 관리자, 2026-11-16)

- 알림 벨 없음
- 하단 "관리자에게 문의" 없음
